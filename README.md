# 🎓 CampusIQ

> AI-powered campus intelligence platform built with Databricks.

CampusIQ brings academic, student, research, events, clubs, and opportunity
data into one unified platform, making campus information easy to discover
through natural-language queries.

## ✨ Features

- 🤖 AI-powered campus assistant with Databricks Genie
- 📊 Unified Lakehouse architecture
- 🎓 Student & professor insights
- 🔬 Research project discovery
- 💼 Opportunities & internships
- 🎉 Events & clubs
- 🔎 Natural-language data exploration

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Data Platform:** Databricks & Unity Catalog
- **AI:** Databricks Genie
- **Architecture:** Bronze → Silver → Gold

## 🚀 Vision

**One intelligent platform for the entire campus — turning campus data
into meaningful insights.**

Built for the **Databricks Campus Hackathon**.
