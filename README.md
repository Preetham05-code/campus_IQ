# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/0d5abdc3-35b4-47c5-a302-862d3d6ee927

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set `DATABRICKS_HOST`, `DATABRICKS_TOKEN`, `DATABRICKS_WAREHOUSE_ID`, `DATABRICKS_GENIE_SPACE_ID`, and `DATABRICKS_CATALOG=workspace` in `.env.local`
3. Run the app:
   `npm run dev`
